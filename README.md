# 🎓 Student Portal

A simple and secure **Student Portal** where college students can log in using their **College Roll Number and Password** and access their personal academic and college-related information.

## 📌 About the Project

The Student Portal provides students with a personalized dashboard after successful login.

Students do not add or modify their information. Their college data is already stored in the system, and after authentication, each student can view their own information.

## ✨ Features

* 🔐 Student login using College Roll Number and Password
* 👨‍🎓 Personalized student dashboard
* 📚 View academic information
* 🏫 View college and course details
* 📊 View student-related records
* 🔎 Student-specific data display
* 🚪 Secure logout option

## 🔑 Login System

Students log in using:

* **College Roll Number**
* **Password**

After successful authentication, the student is shown only their own information.

```text
College Roll Number + Password
          ↓
      Login
          ↓
   Authentication
          ↓
 Student Dashboard
          ↓
   Personal Data
```

## 📋 Student Information

The dashboard can display information such as:

* Student Name
* College Roll Number
* Course / Program
* Branch / Department
* Semester
* College Email
* Contact Information
* Academic Details
* Attendance
* Examination / Result Details
* Other College Records
